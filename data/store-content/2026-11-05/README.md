# 첫 매장 상세 검수 자료

이 자료는 [이슈 #81의 기존 매장 30곳](../../store-imports/2026-11-05/README.md)에 연결할 소개 30건과, 11곳의 확인된 편의시설 16건을 담는다. 매장 ID뿐 아니라 기존 매장명과 주소를 대조한다. 소개는 지점과 운영사 공식 안내의 사실을 다시 작성했으며, 지점 주소와 상호의 근거는 기존 자료와 함께 확인할 수 있다. 팝마트 매장 성격은 [공식 브랜드 소개](https://www.popmart.com/us/brand-introduction)와 [국내 지점 안내](https://www.popmart.com/kr/store-list)를 함께 참고했다.

입점 시설의 주차·와이파이는 공용임을 메모에 표시했다. 편의시설 배열이 생략된 지점은 아직 확인한 항목이 없으므로 기존 확인 값을 덮어쓰지 않는다. 사용 근거가 확보된 사진은 없어 사진 배열은 생략했다.
