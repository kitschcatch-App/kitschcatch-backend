# KitschCatch Backend

서브 컬처 굿즈 탐색, 중고 거래, 오프라인 매장 위치 정보를 한곳에서 연결하는 종합 플랫폼 KitschCatch의 백엔드 리포지토리입니다.


## 1. 프로젝트 소개

**키치캐치**는 가챠, 피규어, 굿즈 등의 서브 컬처 상품을 더 쉽고 빠르게 찾고 거래할 수 있도록 돕는 서비스입니다.

> 기존에는 서브 컬처 문화를 기반으로 하는 플랫폼이 없었기에 분리되고 부족한 정보를 찾기 위한 소비자의 탐색 비용이 크다는 문제가 있었지만, 
> 키치캐치는 굿즈 탐색, 중고 거래, 오프라인 매장 정보를 하나의 플랫폼에서 보다 편리하게 제공합니다.
